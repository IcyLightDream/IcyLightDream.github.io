为什么我放弃了Arch？ | CachyOS 使用体验与优缺点分析

2025/5/10 科技 科技 Linux

CachyOS is designed to deliver lightning-fast speeds and stability, ensuring a smooth and enjoyable computing experience every time you use it. Whether you’re a seasoned Linux user or just starting out, CachyOS is the ideal choice for those looking for a powerful, customizable and blazingly fast operating system.

CachyOS 的设计旨在提供快如闪电的速度和稳定性，确保每次使用时都能获得流畅、愉快的计算体验。无论您是经验丰富的 Linux 用户，还是刚刚开始使用，CachyOS 都是那些正在寻找功能强大、可定制且速度极快的操作系统的用户的理想选择。

（来源: CachyOS 官网）

CachyOS 有什么优点？

基于 Arch Linux

隔壁 Manjaro 强行加 Arch 源可能会炸，但是 CachyOS 自带了 Arch 源，可以轻松从 Arch 转过来（甚至不用重装）

CachyOS 的 /etc/pacman.conf

...
[cachyos-v3]
Include = /etc/pacman.d/cachyos-v3-mirrorlist
[cachyos-core-v3]
Include = /etc/pacman.d/cachyos-v3-mirrorlist
[cachyos-extra-v3]
Include = /etc/pacman.d/cachyos-v3-mirrorlist
[cachyos]
Include = /etc/pacman.d/cachyos-mirrorlist
...
[core]
Include = /etc/pacman.d/mirrorlist
[extra]
Include = /etc/pacman.d/mirrorlist
[multilib]
Include = /etc/pacman.d/mirrorlist
...

同时，CachyOS 源中有大量优化的软件包和编译过的 AUR 包，可以用 pacman -Sl <repo> 查看

可自定义的安装过程

不同于 Arch 的 CLI 安装， CachyOS 采用和其他 Linux 发行版差不多的 GUI 安装界面，并且用户可以自行选择系统引导管理器、桌面环境、内核、文件系统等

支持的 Boot Manager（系统引导管理器）：

GRUB （推荐，常用）
systemd-boot （默认）
rEFInd
Limine

支持的 Filesystem （文件系统）

Btrfs （推荐，默认，后面会详细说）
EXT4 （较推荐，经典）
XFS
ZFS
F2FS
BcacheFS （比较新，据说还可以，可能 bug 有点多，不太建议）

CachyOS 有什么缺点？

对比 Arch

由于使用了更激进的优化，一些硬件可能会不兼容

安装的定制化程度会比 Arch 低点，毕竟是 GUI （不过也可以用 CLI 安装）

注：国内安装之前一定要手动改一下 /etc/pacman.d/mirrorlist ，不然下载会非常慢，建议在安装过程中把 live 环境中的 mirrorlist 复制到系统中

sudo nano /etc/pacman.d/mirrorlist
# 下面这几行随便加上一个就行
Server = https://mirrors.ustc.edu.cn/archlinux/$repo/os/$arch
Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch
Server = http://mirrors.aliyun.com/archlinux/$repo/os/$arch

sudo nano /etc/pacman.d/cachyos-mirrorlist
# 下面这几行随便加上一个就行
Server = https://mirrors.ustc.edu.cn/cachyos/repo/$arch/$repo
Server = https://mirror.nju.edu.cn/cachyos/repo/$arch/$repo

sudo nano /etc/pacman.d/cachyos-v3-mirrorlist
# 下面这几行随便加上一个就行
Server = https://mirrors.ustc.edu.cn/cachyos/repo/$arch_v3/$repo
Server = https://mirror.nju.edu.cn/cachyos/repo/$arch_v3/$repo

sudo nano /etc/pacman.d/cachyos-v4-mirrorlist
# 下面这几行随便加上一个就行
Server = https://mirrors.ustc.edu.cn/cachyos/repo/$arch_v4/$repo
Server = https://mirror.nju.edu.cn/cachyos/repo/$arch_v4/$repo

对比其他发行版

Arch 系发行版不太稳定，建议多备份

我为什么从 Arch 换到 CachyOS ？

更轻松的安装

其实一点也不轻松，安装卡了好几回才发现自动选择的Arch软件源下载太慢了

不需要自己分区，不需要自己安装桌面环境，还送桌面环境配置和一些软件的配置，感觉 Arch 装半天白装了，不如直接装 CachyOS

Btrfs

传统的 ext4 格式如果分 / 和 /home 两个分区的话总是怕一个分区满了而另一个还剩很多，但是 Btrfs 支持子卷 (Subvolume) ， / 和 /home （甚至更多）可以共用一个分区


(可以通过 sudo pacman -S btrfs-assistant 安装)

这些子卷可以单独备份（增量备份）、还原，并且创建备份不需要等待

除此之外，对于不常用的文件可以使用 zstd 算法压缩（手动），和 Windows 中 文件/文件夹右键属性 -> 压缩 一样不影响使用，而且效果更好

不过， Btrfs 文件读写性能会低于 ext4 ，对旧硬件支持也不太好，机械硬盘不太适合用

软件源

CachyOS 的软件源可以节省编译 AUR 包的时间，而且不用担心 Github 10kbps 下载速度的问题
